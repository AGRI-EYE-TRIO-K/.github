## 👁️ The TRIO K Concept

- 🛰️ **Satellite Intelligence:** Online agricultural analysis using Google Earth Engine and supported satellite datasets.
- 🚁 **Drone Intelligence:** Identify candidate areas for targeted field inspection and support geospatial mission workflows.
- 🌱 **Offline Intelligence:** Analyze supported local geospatial data, including GeoTIFF imagery, when internet access is limited.

## 🌾 Key Features

- GIS mapping and farm-boundary workflows.
- Vegetation indicators such as NDVI.
- Supported moisture and crop-stress proxy indicators.
- Crop-specific agricultural analysis.
- Drone inspection planning and supported KML/KMZ exports.
- Reports and geospatial data exports.
- Multilingual application and website.

**Supported crop workflows:** Wheat, Potato, Corn, Olive, Peanut/Groundnut, Universal Analysis, and Soil Analysis.

*Available features and indicators depend on the selected workflow, input data, and application version.*
